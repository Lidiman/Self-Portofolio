# Bama's Personal Portfolio Website

Portfolio modern, ultra-fast, dan accessible untuk **Nabil Aswangga Hugobama (Bama)**.

## Tech Stack
- **Framework:** [Astro](https://astro.build/) (Static Site Generation / Islands Architecture)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide Icons](https://lucide.dev/)
- **Data Source:** Astro Content Collections (Strict Zod Schema)

## Quick Start
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Check TypeScript & Astro types
npm run check

# Build production bundle
npm run build

# Preview production build
npm run preview
```
